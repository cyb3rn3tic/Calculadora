# Calculadora
![](./.docs/calculador.gif)

## Introdução

Uma calculadora criada como primeiro projeto durante o curso da Acadêmia do Programador.

## Funcionalidades

- **Operações básicas**: Realize somas, subtrações, multiplicações e divisões com facilidade.
- **Suporte a numeros decimais**.
- **Tratamento de divisão por Zero**.
- **Tabuada**: a calculadora é capaz de realizar a tabuada do numero informado.
- **Historico de operações**: você pode consultar o histórico das operações que realizou.

## Como utilizar o programa

1. Clone o repositorio ou baixe o codigo comprimido em .zip.
2. Abra o emulador de terminal e navegue até a pasta raíz.
3. Utilize o comando abaixo para restauar as dependências do projeto.

    ```
    dotnet restore
    ```

4. Em seguida compile e execute o projeto com o comando:

    ```
    dotnet run --project Calculadora.ConsoleApp
    ```
